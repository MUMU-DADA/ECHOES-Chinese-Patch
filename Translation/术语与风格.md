# ECHOES 汉化术语与风格

## 人物语气

- 青年：受过战斗训练，叙述简短、克制，前期称少女为“这家伙”，带有明显戒备。随着共同生活推进，逐渐改用“她”；静默结局中重新转回敌意和去人格化表达。
- 少女：故障语句保持简短、直白。虚构语句未解读时不显示中文；玩家掌握组成该句的全部音素后，补丁才追加中文释义。
- 童年日记：使用儿童口吻，句式简单，保留原文留白和断行。

## 固定术语

| 日文 | 简体中文 | 说明 |
|---|---|---|
| アンドロイド | 仿生人 | 统一用于家务型和一般个体 |
| アンドロイド兵 | 仿生兵 | 战斗个体，界面中保持简短 |
| 言語回路 | 语言回路 | 保留机械设定色彩 |
| 分かった音 | 已辨之音 | 指玩家已经辨明的虚构文字发音 |
| 印 | 符号 | 指可拖动、排列的虚构文字 |
| 解読 | 解读 | 用于玩法、教程和系统提示 |
| こだま | 回声 | TRUE END 名称 |
| 残響 | 余响 | BAD END 名称 |
| サイレント | 静默 | BAD END 名称；内部路由值不修改 |

## 有意保留的日文

- `hiraganaName`、物品假名读音、假名行表：它们参与音频、符号顺序和答案判定，不能翻译。
- `{echo:...}` 标签及标签内文本：它们驱动虚构文字渲染和发音，不能替换为中文。
- 单个已知假名提示：运行时改成罗马音，例如 `し -> shi`、`つ -> tsu`。
- 制作人员姓名：保持原始写法。
- 资源对象名、动画名、贴图名和内部路由名：不会展示给玩家，保持原值以免破坏引用。

## 文本处理规则

- 保留 `{0}`、`{1}` 等运行时占位符。
- 对话在进入逐字显示前翻译，避免先显示日文再瞬间替换。
- 静态场景文字在插件加载时主动扫描一次；后续创建的文本在 `OnEnable` 时处理。
- 正常剧情和 UI 使用精确原文匹配，不做模糊替换，避免误改存档键、物品 ID 和成就 ID。
